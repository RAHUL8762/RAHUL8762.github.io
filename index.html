2.1

Channel Equalization in MIMO Systems

MATLAB · Experimental analysis

Problem
Signal distortion, noise and interference in wireless channels.
Method
Compared LMS, Zero Forcing (ZF) and FLANN-LMS adaptive equalization, structured around signal-to-noise ratio (SNR) and bit error rate (BER), to see how each responds to changing channel conditions.
Finding
FLANN-LMS proved effective at adapting to nonlinear patterns and variable channel characteristics. The study also sets out the performance trade-offs between the methods.

3.1

Retail Sales & Profitability Intelligence

SQL · Excel · Power BI Scoped, results to follow

Question
What drives revenue, and which products are underperforming?
Method
Model orders, items, customers and products with SQL joins, CTEs and aggregations. Calculate revenue, order count, average order value and category performance. Clean duplicates, missing values and inconsistent categories, then reconcile SQL totals to source. Build a Power BI dashboard with date, region and category filters, period comparisons and drilldowns.
Data
Olist Brazilian E-Commerce Public Dataset (Kaggle)
Limit
The source has no product cost, so gross margin needs a separately documented cost assumption.
3.2

Customer Segmentation & Retention Analysis

SQL · Python/Pandas Scoped, results to follow

Question
How do high-value, at-risk and newly acquired customers differ, and where are the retention opportunities?
Method
Use SQL window functions and date logic for recency, frequency, monetary value (RFM), repeat-purchase rate and cohorts. Use Pandas for exploratory analysis, outlier treatment and segment validation. Present segment-level KPIs and visualizations.
Data
Online Retail II (UCI Machine Learning Repository, Daqing Chen, 2012)
Limit
Transaction data shows patterns, not causes. Findings will keep observed patterns separate from causal conclusions.
3.3

Operations & Inventory Exception Monitoring

SQL · Excel Scoped, results to follow

Question
Which items need attention because of unusual demand, price changes or possible stockouts?
Method
Combine daily item-level sales with store-level prices to estimate sales velocity, rolling demand, slow movers and stockout exposure. Flag exceptions with SQL CASE expressions, window functions and rolling averages, using transparent thresholds. Summarize priority items in an Excel exception tracker with recommended replenishment actions.
Data
M5 Forecasting, Accuracy (Walmart unit sales, calendar and prices, Kaggle)
Limit
The dataset has no stock-on-hand figures, so inventory turnover and true stock coverage cannot be calculated from it.
